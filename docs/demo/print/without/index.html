Before you start: prepare four things

Checklist

· A computer with a terminal (macOS, Linux or Windows)

· Network access: the office network, or the VPN

· An access token: it starts with mer_ followed by letters and digits

· About 15 minutes

A token is a password Never paste it into a chat, an email or a screenshot. This guide never asks you to print it.

Terms used in this guide (a quick reference)

TermPlain meaning
TerminalA window where you type commands to the computer.
CommandOne line of text you paste into the terminal, then run with Enter.
merThe command-line tool for Meridian Cloud.
Meridian CloudThe hosting service that runs your projects.
TokenYour personal key to Meridian Cloud. Treat it like a password.
ProjectA folder of files that you deploy together, as one unit.
How to paste In the terminal press Ctrl + V, or right-click.
Pasting does not run the command: press Enter when you are ready.

Check your connection

Like knocking on the door before you go in
Copy the line below, paste it into the terminal, press Enter
mer status

You will see one of two results:

Connected: you are ready
Terminal
you@laptop:~$ mer status
Connected (42 ms)
you@laptop:~$ _

“Connected” means the door answered. Carry on to step 2, and keep this window open.

Timed out, or an error message appears instead
Terminal
you@laptop:~$ mer status
Timed out after 10 s

You are probably away from the office network. Join the Wi-Fi or the VPN, then run the command again.

Why does it say “Connected” and not “Signed in”? This check does not send your token, so Meridian Cloud only confirms that it can be reached. Signing in comes next, in step 2.

2

Sign in

Do this once, and never again

2-1 Find your token file

If your team set up Meridian for you, the token is already saved in a small file in your home folder. We read it from there, so you never have to see it or copy it by hand.

Paste, then press Enter
ls ~/.mer/credentials
A file name appears: go to 2-2
Terminal
you@laptop:~$ ls ~/.mer/credentials
/home/you/.mer/credentials
No such file: ask for a token
Terminal
you@laptop:~$ ls ~/.mer/credentials
ls: no such file or directory

Ask your team lead for a Meridian token.

2-2 Sign in with it

This is one long line; it wraps on screen, which is fine
mer login --token-file ~/.mer/credentials --profile default --no-browser --save-profile

You should see “Signed in”. The command reads the token by itself, so you never need to look at it.

2-3 Check who you are

mer whoami
Terminal
you@laptop:~$ mer whoami
Signed in as ada@example.com (team: platform)

Stuck? Start here

What you seeWhat to do
401 Unauthorized
(in the terminal)		The token is missing or wrong. Repeat step 2 and open a new terminal window.
Timed outYou cannot reach the service. Join the office Wi-Fi or the VPN and repeat step 1, then check that you see Connected.
Project not foundThe project name is wrong, or you do not have access yet. Ask your team lead to add you to the team.
400 invalid profileThe profile name in step 2-2 was typed differently. Paste the whole line again.
command not found: merThe tool is not on your PATH. Ask your IT team, then open a new terminal window.
Not signed inRun mer whoami. If it fails, repeat step 2-2.
Safety checklist · Your token is a password, so never take a screenshot of it or paste it into a chat.
· Check that the address starts with https and shows a padlock before you type anything here.
