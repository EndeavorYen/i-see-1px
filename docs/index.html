Without vs with, live

Two real submissions from the same vague brief, same model, same prompt. The only difference is whether the skill was loaded. Both pages run live below; the overlay is measured from their DOM as you watch.

Gray dashed lines are the reference; soft violet is the measurement. A solid line with a filled tag is off; a dashed line with an outlined ✓ tag is aligned or on scale.
